# 한 상

> 지금 밥 먹는 누군가와, 같은 식탁에서.

바닷가 노포에서 낯선 사람들과 한 식탁에 앉아 함께 밥을 먹는 3D 웹 서비스예요.
말없이 편하게 먹어도 괜찮고, 짠·한입 같은 동작과 채팅으로 인사할 수 있어요.

## 바로 실행하기

설치할 것 없이 `index.html`을 브라우저로 열면 돼요.
(three.js와 글꼴은 인터넷에서 불러와요.)

## 주요 기능

- **식탁**: 닉네임·옷 색·메뉴를 고르고 자리에 앉기, 한입·물·짠·리필, 같은 테이블 채팅
- **내 음식**: 음식 사진을 올리거나 글로 적으면 비슷한 3D 요리를 만들어 식탁에 올려요
- **해변 산책**: 혼자 또는 함께, 타올·파라솔, 패션(선글라스·모자·양산), 불꽃(폭죽·손불꽃)
- **계절**: 여름 물놀이(자유형·배영·비치볼·튜브), 봄 벚꽃·가을 단풍과 연날리기, 겨울 눈놀이(눈사람·눈싸움)
- **풍경**: 시간·계절·날씨(맑음·흐림·비·눈) 바꾸기
- **소리**: 음식·파도·비·바람·동물 소리를 따로 조절 (모두 코드로 만든 소리)
- **사진**: 지금 장면을 찍어 사진첩에 저장

## 폴더 구성

```
index.html          서비스 전체 (HTML·CSS·JS 한 파일)
tools/soundlab.html 소리를 하나씩 들어 보고 고르는 실험실
tools/build_lab.py  index.html에서 소리 코드를 뽑아 soundlab.html을 만드는 스크립트
```

## 배포

GitHub Pages: 저장소 **Settings → Pages**에서 브랜치 `main`, 폴더 `/ (root)`를 고르면
